# EducationHelper 1.5.4

## 本次修复

PDF 预览补齐本地 CMap、字体及 WASM 解码资源，并支持缩放、适应宽度和重试。构建时从锁定的 pdfjs-dist 复制到静态目录，不需访问 CDN。

分析页和试卷分析弹窗提供发布批次选择，默认最新未撤销批次（全部撤销时取最近批次）。不会把同一学生不同考试当成同一次统计；Excel/PDF 下载与当前批次一致。AI 的 `paper.analyze` 支持 `publication_id`，可先用 `paper.publications` 查询。

Excel 增加中文成绩单、得分率、单位、批次编号、同分并列排名和逐题成绩。未完成批改的成绩留空；原英文数据页保留兼容，用户姓名等文本禁止作为公式执行。PDF 保留现有报告版式。

删除考试记录是可选需求，本次未实现，避免删除历史答卷和成绩。

## 旧题库迁移与权限

更新前备份平台数据库、内容目录和配置目录。题库首次由登录教师访问时迁移：

- 将原共享 `resource/`（排除私有目录）复制到 `.solaire/legacy_bank_snapshot/`，记录迁移时已有教师。
- 为这些教师各自创建 `resource/__teachers/<教师ID哈希>/` 独立副本；旧题目嵌入图片路径转向副本。
- 之后新增教师从空题库开始。各教师新增、修改、删除题目互不影响；新题目导出也分教师存储。
- 原共享文件不删除，用于兼容此前生成的历史试卷。旧数据没有题目所有者，不能可靠推断归属，因此不会擅自将原题只分给某一教师。

网页题库及 AI 文件/文档工具校验私有路径；跨教师读写拒绝。管理员仍可管理内容。部署必须启用公开访问权限控制，使用有效登录凭证；开发模式不是多租户安全部署方式。

迁移在现有单进程后端内串行执行，不声明支持多 worker 并发迁移；首次访问可能因旧题库大小耗时。暂存及不完整目录保留，便于管理员恢复，勿手动删除原题库。
