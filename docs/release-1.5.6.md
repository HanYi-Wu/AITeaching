## 数据兼容与能力边界

- 新增数据库列通过现有迁移机制补齐；不清空既有资料。老教师不强制改已有密码，新版引导首次显示并保存进度。学校新建/重置教师密码会要求改密。
- 引导是强制顺序的页面教学，不会为了流程完成偷偷创建考试、提交成绩或让AI付费。每步确认表示已经了解，不代表已产生业务数据。
- 教师主动识别关系符按语法解析，且优先于或；不自动猜测自然语言或数学括号的含义。复杂旧题由AI读取题意后适配，已发布快照保持不变。
- CDK是持码邀请，已登录教师可复制指定快照，非教师不可使用。有效7天，最多300题、图片50MB。同名目录不合并、不覆盖；一码同教师只导入一次。撤销不会删除已复制内容。
- 源题干、选项、答案、解析和题组中的嵌入图片引用都随快照复制并改写到接收教师私有路径；保留题目学科，来源标记教师分享。图片缺失/越权则拒绝分享。
- GitHub Release 提供 Linux x86_64 完整离线安装／更新包及 SHA256 校验文件；包不包含本地账号、考试、上传资料或密钥，也不自动更新已部署服务器。Windows exe 暂不制作。桌面启动器仍使用已有65账号的独立验收数据目录，地址 http://127.0.0.1:5155，密码 EHtest155!。
