# EducationHelper 1.5.7

本次为 1.5.6 后的修复版，完整 Linux x86_64 离线包包含应用、前端成品、Python 运行环境、安装／更新入口和旧数据修复模块。目标机无需联网安装依赖，原业务目录与配置保留。更新前自动备份数据库，失败回滚代码；不以旧备份覆盖更新期间的新答卷。

主要修复：

- 题目创建超时后找回已成功创建的题目，阻止重复请求覆盖题目；编辑时锁定题目编号。
- 发布试卷前拒绝无题目或缺失题目内容；教师不能覆盖其他教师同路径试卷，分析按班级筛选并关联 AI 工具。
- 批改页展示参考答案，批改及学生薄弱题支持题目嵌入图片；PDF 预览修复跨题库图片引用。
- 正式 PDF／Word 导出文件可在浏览器下载，不再只有预览文件可下载。
- 离线安装器在停服前备份并运行旧数据修复；无法确认归属或来源的记录报告为 `unresolved`，不会猜测、伪造或删除数据。

安装方式及数据修复说明见 `docs/linux-offline-install.md`。包仅支持 Linux x86_64、glibc 2.35+、systemd；不包含用户数据、密钥和 Windows EXE。部署后仍需以实际教师及学生账号验收业务流程。
