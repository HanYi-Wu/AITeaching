# 1.5.5 验收说明

本次仅源代码更新，不生成安装包。`EH_DATA_ROOT` 指定独立数据目录，未设置时沿用原有资料位置。

## 资料兼容

旧共享题目没有可靠归属，不能认定复制给教师就成为其原创。首次访问时比对 `.solaire/legacy_bank_snapshot`，只将完全未修改的继承 YAML 移入 `.solaire/bank_quarantine/<教师哈希>/原相对路径`。新增和修改后的文件保留。原始共享题目、图片和历史已发布快照保留。管理员需核实归属后恢复，不能凭空推断所有权；迁移完成后的恢复文件不会再次自动隔离。

旧无时区的发布时间解释为北京时间，新发布时间携带时区。只设置开始时间，不会在一分钟后自动结束；需要设置结束时间。

教师通过助手 `bank.legacy_answer_candidates` 自动发现旧答案候选，再由 `bank.adapt_answers` 适配新旧多答案。助手先读取真实题目结合题意解释“或者/且/和”等，不机械替换自然语言，每批最多50题、一次确认，并保留原答案。不会改动历史试卷快照。结构等价判定不代表通用数学公式语义等价，后者仍需教师或AI判断。

## 要求、解决方式及测试方式

| 要求 | 解决方式 | 测试方式 |
|---|---|---|
| 旧题库隔离 | 未修改继承副本隔离，新增/修改题目保留 | `test_teacher_private_bank.py`：双教师同ID、HTTP/AI越权、迁移保留 |
| 全选择题自动成绩 | 提交事务内评分和发布，未答0分；混合题审核 | `test_platform_student_api.py`：提交流程及立即查成绩 |
| 考试时间 | 时区明确、旧值北京时间、截止校验、动态窗口 | `test_publication_time.py`：UTC/北京时间等价及过期窗口 |
| 弱网加载 | 页面分块、Mermaid按需、资源预压缩与哈希缓存 | 生产构建、`test_offline_frontend.py`、浏览器网络面板 |
| 切页白屏 | 独立加载/错误边界，不隐藏导航；网络失败提供重载 | 浏览器切页；`WorkspaceLoadBoundary.test.tsx`注入工作区错误 |

## 本地测试数据

`python scripts/seed_acceptance_155.py --data-root .planning/acceptance-1.5.5` 生成账号表 `测试账号.md`。拒绝覆盖已有非验收目录，样例为合成答题，不是真实学生表现。已有AI配置首次复制到验收目录，启动时同时设置 `SOLAIRE_USER_CONFIG_DIR=<验收目录>/config`，避免验收设置改动原配置；配置及账号资料不提交Git。
