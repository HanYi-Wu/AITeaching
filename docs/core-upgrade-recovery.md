## 开发源码恢复

本地保留 `restore/1.6.7-319f189` 分支。工作目录干净时，执行：

```powershell
git switch restore/1.6.7-319f189
```

Git 会阻止覆盖冲突的未提交修改。先提交需要保留的工作，再切换分支；无需强制重置。
也可以在任意新目录解压仓库外的 `1.6.7升级前源码-319f189.zip`；同目录 `.sha256` 文件用于核对完整性。
该压缩包使用 `git -c core.autocrlf=false archive` 从基线提交导出，避免本机换行配置改变归档字节。
已使用源码核验工具逐文件比对 Git blob；核验结果在仓库外 `1.6.7恢复包核验.json`。
压缩包包含该提交跟踪的源码，不含本次开发改动。

具体提交范围以最终交付记录为准，不使用未经核对的批量重置或强推。
