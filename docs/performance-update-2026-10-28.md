# 性能优化与兼容性修复

日期：2026-10-29

本次更新改进题库筛选、富文本编辑、学生草稿保存、扫描答卷处理、双份试卷渲染、助手流式显示和图谱交互。优化保留既有公开接口和数据格式，并对异步请求、权限复核和失败恢复补充回归验证。

## 页面交互与内容归类

- 登录密码输入框隐藏浏览器重复的显示密码按钮，保留页面原有的显示与隐藏操作。
- 题目已有悬浮预览时移除重复的原生提示，保留可访问名称。
- 页面密度应用账号已保存的偏好；紧凑模式减少工作区间距、卡片留白与表格行距，退出账号后恢复默认密度。
- 组卷历史与试卷列表支持多选、全选当前可见项、拖拽所选内容及选择目标文件夹批量移动。移动失败保留选择并显示错误；批量试卷移动在同一事务内校验全部归属和发布历史，校验失败不移动任何试卷。
- 已有发布记录的试卷继续通过移动整个文件夹归类，撤销发布后也保留该限制，避免改变原答卷和统计关系。
- 分析页增加独立文件夹，支持新建、重命名、删除、筛选和批量归类。归类按教师与项目保存，删除文件夹只移除分类关系；试卷、成绩和答卷保留。损坏的分类记录不会被空数据覆盖。
- 学生成绩支持按标题、学科和考试编号搜索，并按学科、批改状态筛选。设置页居中显示，修改密码与用户名分别放在独立区域，窄屏时纵向排列。

## 题库与组卷

- 仅在实际搜索时构造全文搜索文本，避免浏览列表和切换筛选条件时提前序列化全部题目。
- 搜索索引跟随当前题目快照，重新加载或替换题目列表后重新建立，避免复用旧数据。
- 组卷按学科组织题目，并提前解析元数据筛选条件，减少每道题重复解析相同筛选规则。
- 题库目录读取减少不必要的模型复制和重复路径处理；单题读取继续检查重复题号、非规范文件名和项目路径边界。
- 保留题组、扩展字段、诊断、大小写无关搜索和原有结果顺序。

## 富文本与试卷渲染

- 外部内容更新时，复用内容完全相同的静态公式和表格预览；文本、图片和异步图表重新建立，避免资源路径与异步结果串用。
- 保留编辑过程的焦点、选区和原生撤销行为。编辑器卸载后取消待执行的输入法提交，节点与笔记切换使用独立编辑实例。
- 学生卷和教师卷在一次导出中共用模板准备、图片路径整理和题号投影；两次渲染分别取得独立的题目与章节容器，避免自定义模板修改容器后影响另一份试卷。
- 保留独立渲染入口，连续导出能够读取更新后的模板，不跨项目缓存同名模板。

## 学生作答与线下答卷

- 草稿保存只发送相对已确认版本发生变化的题目，清空答案或图片也作为变化发送。最终交卷继续携带完整答案。
- 保存回执按请求所属试卷及版本确认，防止旧请求覆盖后续输入；切换试卷或账号后，迟到的处理结果不会写入当前答卷。
- 本地存储写入失败时，限量保留尚未确认的文字和图片草稿，并提示离页风险；缓存记录优先保留最近写入失败的内容，成功写入或删除后及时清理临时记录。
- 数据库读取复用连接，客观题评分批量写入，保留原有计算顺序、精度、舍入和重复交卷回执。
- 写入事务内重新检查学生、答卷状态及所属关系，防止检查后状态发生变化时继续写入。
- 扫描上传在读取和解码照片前检查试卷、班级、学生及已批改状态，正式写入时再次复核。
- 扫描照片逐页处理并限制同时解码的数量，转换输出也受体积上限约束。快速压缩接近体积限制时回退原压缩方式，保留原有可接受范围。
- 取消排队任务后不再读取照片；已开始的处理保留文件句柄至安全结束，并在开始事务前检查取消状态。

## 助手与图谱

- 流式文本按显示帧合并，操作回执及结束事件到来前先输出此前文字，减少重复复制历史消息和刷新页面。
- 历史消息与执行卡片使用稳定标识，保留执行结果到达顺序，并支持不同轮次复用调用编号。
- 创建会话、附件上传、流式连接和历史加载使用所属会话检查。新建聊天或卸载后，旧请求不能修改新会话或解除新请求的忙碌状态。
- 会话保存使用紧凑文本；读取和历史列表继续执行完整结构验证，保留所有者筛选与路径检查。
- 图谱仅在节点尺寸、保存坐标、拓扑、关系筛选、布局模式或显式重排发生变化时重新求解；名称、描述等更新保留当前坐标、拖拽和选择状态。
- 防重叠处理预先读取节点尺寸和半径，减少节点对循环中的重复查找与对象分配，保持坐标计算顺序。
- 图谱按账号和项目隔离状态，切换后清理旧图数据、选择、连接与撤销记录，并拒绝旧请求回写。
- 修复保存节点期间切换节点后忙碌状态未解除的问题；同节点数据刷新保留尚未保存的编辑，旧节点的保存或删除回执不再影响新节点。
- 节点更新只合并明确提交的字段，保存笔记不再清空未提交的标签、别名或来源。显式清空主父节点及其他可空字段能够正确保存。
- 删除节点后的撤销恢复保留笔记与来源信息。

## 同条件性能对照

下表使用合成数据及前后交错测量。各行覆盖的范围不同，不能相加或统一理解为整个应用的耗时。

| 场景 | 优化前中位数 | 优化后中位数 | 测量范围 |
|---|---:|---:|---|
| 1,000 题目录读取 | 658.2 ms | 569.5 ms | 本地目录读取及投影 |
| 10,000 题列表，无搜索 | 5.004 ms | 0.015 ms | 列表筛选与搜索准备，不含页面绘制 |
| 10,000 题组卷，重复全文搜索 | 5.443 ms | 0.787 ms | 已建立索引的纯数据处理 |
| 100k 字符混排内容，外部插图更新 | 13.0 ms | 9.4 ms | 开发环境浏览器更新，30 组交错样本 |
| 20 页扫描答卷 | 1,305.0 ms | 828.2 ms | 本地上传处理，3 组交错样本 |
| 已批改答卷的覆盖拒绝 | 1,239.0 ms | 5.1 ms | 本地上传处理，提前拒绝后不再解码照片 |
| 19 题学生卷与教师卷 | 33.628 ms | 17.486 ms | 本地模板准备、渲染及两份文本写入 |
| 100 题学生卷与教师卷 | 34.311 ms | 20.122 ms | 本地模板准备、渲染及两份文本写入 |
| 5,000 个已就绪流事件 | 22.755 ms | 11.772 ms | 本地队列分发，不含网络与模型响应 |
| 1,000 个节点防重叠处理 | 1,559.1 ms | 391.7 ms | 布局内部阶段；前后输出坐标逐项一致 |

200 题图文答卷仅修改少量内容时，草稿请求构造样本从 5,776,487 字节降至 144 字节；该结果不代表所有保存请求，交卷仍发送完整答案。

首次搜索需要建立索引。10,000 题样本中，题库首次全文搜索为 5.232→5.644 ms，组卷首次全文搜索为 5.262→5.949 ms；相应的重复搜索明显减少计算。题库选择器读取在本次样本中基本持平，未计为性能提升。

## 验证范围与限制

- 验证覆盖题库诊断及重复题号、筛选结果与顺序、富文本内容往返、草稿确认及切换、交卷和评分、扫描权限与取消、模板隔离、流事件顺序和图谱状态隔离。
- 两种规模的学生卷和教师卷文本与原实现逐字节一致；防重叠处理在测试样本中保持相同坐标。
- 后端全量回归通过 1,121 项，跳过 4 项；实际文档转换的结构回归已纳入通过范围。
- 前端全量回归通过 109 个文件中的 673 项用例，类型检查与正式构建通过。
- 跳过项包括两个当前环境无法创建符号链接的边界用例，以及缺少识别运行依赖和打包依赖的两个集成用例；未将这些用例记为通过。
- 性能数据不包含真实学校数据、网络等待或完整生产负载。大规模样本用于补充压力观察，不能直接代表日常使用收益。
- 本地试卷渲染数据不包含实际 PDF 排版耗时，也不证明最终文档的视觉分页。完整 PDF 排版与原生桌面安装流程未纳入本次验证。
- 新增页面的完整浏览器视觉复核尚未完成，组件行为回归不能替代最终显示效果检查。未修改的原生模块未在本地重新完成测试。
- 本地存储不可用时，临时草稿仅存在于当前页面内存，刷新或关闭仍可能丢失；应在离页前完成服务器保存。
- 同一富文本字段进行输入法组合输入时，同时发生异步插图更新的既有竞争行为仍需单独处理，本次不将其标为已修复。
