# EducationHelper 1.6.1

本次修复多教师环境下教师从工作区生成试卷与直接发布试卷时出现的权限错误（403 No permission for this paper）。

主要修复：

- 修复组卷工作区保存时意外丢失元数据（metadata）的问题，确保所属教师标识（owner_teacher_id）持续持久化保存于 `exam.yaml`。
- 修复 `POST /api/papers/from-exam` 在多教师环境下将未分配归属试卷直接判定为无权的逻辑；教师显式从工作区同步试卷时支持自动认领所有权并持久化回填至数据库。
- 优化试卷列表查询（`GET /api/papers`），保持为纯只读查询，不隐式抢占试卷所有权，严格保障各教师之间数据隔离。
- 补充多教师场景测试用例，覆盖两名教师分别组卷、同步与直接发布试卷的完整全流程，并验证跨教师越权访问返回 403 受到安全隔离保护。
- 统一前端、后端、命令行及桌面组件版本为 1.6.1；保持版本标签仅发布源码与说明，离线打包保留为手动触发。

更新服务器源码后需重启后端服务，本次不涉及数据库破坏性结构变更。
