# 题目目录与界面修复（本地待发布）

## 使用

- 题库左侧新增逻辑目录。输入 `数学/函数` 可一次创建父目录和子目录；点击目录展开/折叠并选中，再修改路径并点击重命名。
- 勾选题目，选择“移动到目录”，点击“移动已选 N 题”。选择根目录可取消分组，每批最多 500 题。已有搜索、分类、题型筛选同时生效。
- 删除目录及子目录会把其中题目移到父目录，不删除题目。原题目 ID、图片路径和已发布试卷不变。
- AI 可使用 `bank.organize` 列出目录、新建、重命名、批量移动、删除目录。成功后刷新已打开的题库；遵循已有写入确认设置。
- 常用版式：空模板补出可编辑题型；已有出题结构和分值不覆盖。显示应用后的栏数、边距、字号和题数，仍需保存模板。
- 发布记录改成自适应卡片，文字按钮“取消发布”不再位于横向表格外。
- 学生题干、选项与解析沿用携带登录凭证的图片请求；支持中文路径。图片网络/解码错误提供单独重试，不清空答题内容。旧前端显示原始 EMBED_IMG 标记时，需要更新前端并刷新页面，不能只重启后端。

## 数据与 API

目录使用 SQLite 事务，独立于题库原文件。已有题目默认出现在根目录。平台登录用户的目录存储于内容根目录下 `.solaire/bank_organization/<用户ID的SHA256>/bank-folders.sqlite3`；未登录本地开发模式使用 `.solaire/bank-folders.sqlite3`。备份整个 `.solaire` 即可保留目录。

现有题库本身是共享内容目录；本次只隔离每个教师的整理视图，不改造题库所有权。

- `GET /api/bank/folders`：返回 `{"folders": ["数学", "数学/函数"], "assignments": {"math/default/q1": "数学/函数"}}`。
- `POST /api/bank/folders/actions`：JSON 字段 `action`（create / rename / move / remove）、`path`（目录路径）、`target`（重命名的完整目标路径）、`qualified_ids`（移动的 ID 数组）。返回更新后的同结构快照。
- `bank.organize`：同参数，另支持 `action=list`。
- 平台模式要求教师/管理员登录；学校、学生不可调用。非法路径、缺失目录/题目返回 400，参数结构错误返回 422。拒绝合并已有同名目录、自身嵌套和超过 12 层/240 字符的路径；失败时事务回滚。
