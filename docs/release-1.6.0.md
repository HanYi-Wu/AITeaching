# EducationHelper 1.6.0

本次修复教师端创建、重命名和复制试卷时出现的服务器内部错误。发布源码与更新说明，不提供安装包。

主要修复：

- 创建试卷时，不再因为重名检查读到其他教师的试卷而返回 500。
- 重命名、复制及补练试卷使用相同的修正逻辑。
- 保留教师权限隔离和同名保护：其他教师的试卷内容仍不可读取，同名创建会明确提示修改名称，不覆盖已有试卷。
- 补充多教师场景测试，覆盖有配置文件和无配置文件的历史试卷、新建、重命名、复制及同名冲突。
- 同步前端、后端、命令行及桌面组件版本为 1.6.0；GitHub 版本标签只发布源码与说明，离线打包保留为手动操作。

更新服务器源码后需重启后端服务，本次不涉及数据库结构变更或业务数据迁移。
