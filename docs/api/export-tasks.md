# 试卷导出任务

已有同步接口 `/api/exam/export` 与 `/api/exam/export-word` 保持兼容。
新接口允许前端展示任务状态、刷新后查找近期任务，并重试失败任务。

## 接口

| 方法 | 路径 | 行为 |
|---|---|---|
| POST | `/api/exam/export-tasks` | 创建任务，返回 202 和任务状态 |
| GET | `/api/exam/export-tasks?limit=20` | 当前账号近期任务，最多 100 条 |
| GET | `/api/exam/export-tasks/{id}` | 查询当前账号的指定任务 |
| POST | `/api/exam/export-tasks/{id}/retry` | 重试失败任务，返回 202 |

创建请求使用 `ExamExportBody` 的所有原有字段，额外接受：

- `format`：`pdf`（默认）或 `docx`。
- `request_key`：可选，最长 100 字符。一个逻辑提交使用一个稳定标识；重复请求返回同一任务，同一标识搭配不同内容或格式返回 409。

响应包含 `id`、`format`、`status`、`created_at`、`updated_at`、`attempt`、`result` 和 `error`。
状态为 `queued`、`running`、`succeeded`、`failed`。`result` 沿用原导出接口结构；错误包含 HTTP `status` 和 `detail`，其中可能有失败后保存的草稿信息。
不返回内部请求内容、账号资料、凭证或服务器存储路径。

## 权限与故障恢复

公开部署沿用登录中间件。教师和管理员只能查询、重试自己创建的任务；其他账号访问返回 404。学校和学生角色不能调用。
本地匿名模式的任务属于本地工作区；该模式与原有本地 API 相同，不适合直接暴露到公网。
后台执行前重新检查发起账号状态和角色，导出流程再次校验试卷归属。

重复重试正在排队、运行或已成功的任务会返回当前记录，不重复编译。失败重试使用原请求，在当时的权限和文件状态下重新校验。
任务状态保存在当前项目的 `.solaire/export-tasks.sqlite3`；操作系统锁标识后台执行者是否仍然存活。
进程中断后，下一次查询将未完成任务标记为可重试失败，不自动重复产生业务写入。
同一项目的网页与 AI 导出共用编译锁，保护现有共享构建文件；不同项目可以并行。

每账号最多 4 个、每项目最多 12 个未完成任务，超过返回 429；单份请求配置最多 1 MiB。
当前队列使用两个后台线程。任务历史保留在项目内，需随业务数据一起管理；该版本不提供自动清除或跨机器任务调度。

## 兼容性

没有修改原有业务数据库结构、账号、题目、试卷与成绩格式。旧版 1.6.7 忽略新增任务数据库及锁标识。
回到旧版前应先等待当前导出结束；后台任务尚未完成时不能直接将其视为已成功交付。
