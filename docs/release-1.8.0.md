# 源远教学平台 1.8.0

- 智能体浮窗支持标题栏拖动。左右和上边缘以指针越界为收起条件，底边以窗口超过一半移出为条件；松手前拉回可取消，松手后把指针移近边缘标记即可展开标记。
- 智能体可引用页面控件与可见文字；密码、表单值和隐藏内容不采集。图片有独立上传入口，历史在左侧栏，主题与记忆归入设置。生成题目可先预览再批量确认。
- 教师工作台集中显示待处理答卷，可从薄弱题布置个人错题练习。个人练习不进入班级分析。教师设置和引导使用弹窗，学校管理端根据可用宽度切换单列和双栏。
- 学生首页优先展示待做和可继续的试卷。作答节奏仅作为人工复核线索，不判定作弊、不影响成绩。
- 新增版本发现、签名 ZIP 验证、隔离试运行、预约切换和回滚。更新、回滚与主机扩展操作纳入审计。

本版本为源码发布，未附安装包。从 1.7.4 升级涉及数据库结构变动，先备份业务数据并安排维护窗口，不要使用兼容版本的热切换路径。运维配置与演练见 [Linux 安装与更新说明](linux-offline-install.md)。
