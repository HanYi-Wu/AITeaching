# Agent、图谱与任务状态验收

工具目录按领域组合并校验重复名称、缺失 handler 和 schema 关联，保留已有工具参数、选择顺序、确认标签与公共导入。

图谱保留原 YAML、节点标识和旧数据迁移。节点、关系和题目绑定在项目写锁下完成整批校验与更新；跨科目引用和节点标识共享同一把锁。文件替换失败时保留原文件，多文件操作对已捕获的写入错误执行恢复。各文件使用原子替换，不承诺断电时的跨文件事务。

任务状态以既有导出、分析和 Agent 执行机制为准。投影只保存有限元数据，按账号与项目隔离，并校验尝试次数和事件版本。没有实际处理数量时显示阶段文字。成功终态不会被迟到取消覆盖，重试会清除前次结果与错误。查询可核实来源状态，执行进程消失时显示中断或需核对，不自动重放写操作。

Agent 确认和工具执行复核当前账号与学校策略，账号数据库与教学项目使用各自的真实路径。会话执行互斥，消费确认后在工具开始前保存执行位置，重复确认不再次写入。已有事件名称、心跳、步骤更新与确认入口继续兼容，工具事件补充可选的调用标识以区分重传和多次调用。

可选异步预批改复用原有建议生成服务。任务开始、每次模型调用前和写回时重新核权；写回在同一事务内比较人工批改版本。旧同步入口保留，异步入口只生成建议，不发布教师最终成绩。

## 本地验证

- 后端核心整合检查：108 项通过。覆盖工具契约、编排、确认、权限变化、任务投影、异步预批改、图谱及分析服务。
- 故障检查实际覆盖跨进程图谱锁竞争、跨科目重复标识、批量错误不写入、第二个文件写入失败后的恢复、来源中断查询、成功后迟到取消、重复确认及写入后结果未返回的中断。
- 相关前端测试与 TypeScript 检查通过；回归覆盖相同调用事件去重、同一工具多次调用保留、账号/项目/任务切换后的迟到响应和首次查询失败后的重新同步。
- 使用合成教师账号在当前页面验证创建图谱与节点、重命名、关系保存、笔记保存与切换隔离、从题库选择并绑定题目。

复现入口：`tests/test_graph_write_consistency.py`、`tests/test_task_workflow_fault_acceptance.py`，以及现有 Agent、任务适配、图谱与分析测试。

商业模型网络请求使用测试替身；未配置模型的实际界面保持禁用状态。本批不宣称第三方模型、原生应用或真实 OCR 引擎验收通过。完整后端、前端、构建、源码归档及 Rust 检查由现有 CI 执行。
