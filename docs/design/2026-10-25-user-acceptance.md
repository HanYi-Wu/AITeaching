真实浏览器已走通管理员、学校管理员、教师、学生的教学闭环：准备教学内容、组卷、向班级发布、学生作答交卷、教师批改发布、学生查看成绩。最终教师与学生端均显示 35/35，解答题评语一致。发现的四类问题已修复，并在最终生产构建中复验。

使用最新前端生产构建与真实 Python 后端，地址为 `http://127.0.0.1:19032/`，后端端口 19031。测试数据位于单独的临时目录，不连接既有业务数据。基础账号、五道题与四题型模板由测试数据准备；另一个学校及其教师、班级、学生、任课分配通过页面实际创建。所有身份、答卷和成绩均为模拟数据。
