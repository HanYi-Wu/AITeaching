# 1.6.7：模板组卷、文件夹、手机登录与安装兼容修复

本版基于 1.6.6，保留个人练习、分层目录、个人标签和组卷题量调整等功能。

**2026-10-23 同版本修订：保留版本号和发布页面 v1.6.7，替换源码及 Linux 离线包。此前下载过 1.6.7 的用户，请重新下载本页修订包并更新；安装包文件名中的提交编号可区分新旧构建。**

## 本次补充修复

- 连续新建模板、同学科同名新试卷时，自动追加 `(2)`、`(3)`，保护已有文件；手动重命名和保存已有试卷仍拒绝覆盖其他内容。
- 新建试卷前刷新模板列表，确保下拉框显示的模板与实际保存的模板一致；覆盖首次添加、删除、重命名模板后的组卷场景，无模板时禁止提交。
- 模板、组卷和试卷页补齐文件夹删除及确认。普通归类删除后，源文件保留，内容和子文件夹移到上一级；根目录内容回到未归类。含试卷或发布记录的目录受到保护，不删除学生答卷和成绩。
- 同目录新建重名文件夹自动编号，手动重命名与移动重名时提示修改；补充归类文件夹与试卷文件夹的用途、层级、发布和删除说明。
- 手机登录卡片在空间足够时居中；小屏正常滚动，避免顶部裁切。已按手机尺寸实际检查。
- 日志复制兼容局域网 HTTP 页面缺少剪贴板接口和浏览器权限拒绝；不能自动复制时提供手动复制文本。
- 教师分析页不再请求管理员专用脚本、工具接口；后台权限限制保留。未交卷时禁止发布批改结果并说明原因，已有发布记录的试卷提示移动整个文件夹。

## 修复内容

- 题库、模板和组卷的内容编号含 `/` 时，标签读取、保存原先返回 404。现在接口接收完整目录编号，教师之间的标签继续隔离。
- 学生、学校和管理员访问教师目录、标签接口时，原先可能返回 500。现在统一返回明确的教师权限提示。
- 明确声明 `httpx` 运行依赖，修复全新安装缺少模块导致后端不能启动的问题。
- 将 Anthropic 依赖范围与已有 Pixi 配置对齐，修复新安装选入不兼容 SDK 后调用失败的问题；不改变平台使用的 AI 配置。
- 脚本分析的隔离进程和输出读取统一使用 UTF-8，修复 Windows 中文图表分析失败，并验证中文及表情符号输出。
- 各端应用版本及自身 Rust 包的锁文件版本统一为 1.6.7。

## 验证与交付

本次本地回归合计后端 485 项通过、前端 169 项通过，生产构建成功。本机缺少 Tesseract 的 1 项真实 OCR 检查由 Linux 构建中的真实图片识别检查补验。此前目录标签、账号权限、真实 SDK 请求解析及中文脚本执行验证保留。浏览器实测覆盖连续新建模板、重命名后组卷、同名试卷编号、删除归类保留试卷、日志复制、教师分析和手机登录布局。

Linux 离线构建运行上述功能的后端回归、前端测试、真实图片 OCR 检查，并执行真实安装、保留账号和业务数据的升级、故障候选版本回滚验证。具体构建结果以发布提交对应的工作流为准。为减少 Actions 额度消耗，常规检查在本地完成，Linux 构建仅手动运行；发布构建直接上传 Release，不另存 Actions 临时产物。

Release 提供四个下载项：GitHub 自动生成的源码 ZIP、源码 tar.gz，以及 Linux x86_64 完整离线安装包与 SHA-256 校验文件。

离线包包含前端成品、Python 运行环境、Cairo、Tesseract 和中英文 OCR 语言数据，目标机器无需下载 Python 或 npm 依赖。支持 Linux x86_64、glibc 2.35+ 和 systemd。PDF/LaTeX 排版仍需另行配置 TeX 引擎；不包含用户数据、密钥和 Windows EXE。

将 Linux 离线包解压后，在其目录执行 `sudo bash install.sh`。已有部署请沿用原数据与配置目录。详细参数、升级和回滚行为见 [Linux 离线安装说明](linux-offline-install.md)。本次 GitHub 发布不会自动更新正在运行的业务服务器。
