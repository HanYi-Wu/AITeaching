# 1.6.7：标签、中文分析与安装兼容修复

本版基于 1.6.6，保留个人练习、分层目录、个人标签和组卷题量调整等功能，修复本次实际复现的问题。

## 修复内容

- 题库、模板和组卷的内容编号含 `/` 时，标签读取、保存原先返回 404。现在接口接收完整目录编号，教师之间的标签继续隔离。
- 学生、学校和管理员访问教师目录、标签接口时，原先可能返回 500。现在统一返回明确的教师权限提示。
- 明确声明 `httpx` 运行依赖，修复全新安装缺少模块导致后端不能启动的问题。
- 将 Anthropic 依赖范围与已有 Pixi 配置对齐，修复新安装选入不兼容 SDK 后调用失败的问题；不改变平台使用的 AI 配置。
- 脚本分析的隔离进程和输出读取统一使用 UTF-8，修复 Windows 中文图表分析失败，并验证中文及表情符号输出。
- 各端应用版本及自身 Rust 包的锁文件版本统一为 1.6.7。

## 验证与交付

本地已完成后端全量测试、前端测试与生产构建；本次修复另有目录标签、账号权限、真实 SDK 请求解析及中文脚本执行回归覆盖。业务检查涵盖指定学生发放、重复发放拦截、学生答题、自动计分和个人练习与班级统计的分开计算。

Linux 离线构建增加真实图片 OCR 识别检查，并执行真实安装、保留账号和业务数据的升级、故障候选版本回滚验证。具体构建结果以发布提交对应的工作流为准。为减少 Actions 额度消耗，常规检查在本地完成，Linux 构建按需手动运行。

Release 提供四个下载项：GitHub 自动生成的源码 ZIP、源码 tar.gz，以及 Linux x86_64 完整离线安装包与 SHA-256 校验文件。

离线包包含前端成品、Python 运行环境、Cairo、Tesseract 和中英文 OCR 语言数据，目标机器无需下载 Python 或 npm 依赖。支持 Linux x86_64、glibc 2.35+ 和 systemd。PDF/LaTeX 排版仍需另行配置 TeX 引擎；不包含用户数据、密钥和 Windows EXE。

## 安装与更新

将 Linux 离线包解压后，在其目录执行 `sudo bash install.sh`。已有部署请沿用原数据与配置目录。详细参数、升级和回滚行为见 [Linux 离线安装说明](linux-offline-install.md)。本次 GitHub 发布不会自动更新正在运行的业务服务器。
