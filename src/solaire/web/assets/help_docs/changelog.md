# 更新日志

## version 1.5.6

- 题库空白处取消复选；文件管理器新增右键、剪切粘贴、Shift范围选择、拖动题目及目录移动，上一级导航，保留次级目录关系并阻止循环和覆盖。
- 教师可以直接编辑分项多答案及嵌套且/或关系；支持主动识别关系符，至少保留一个答案，空条件拒绝保存；不自动改写旧题语义。
- 新教师首次登录、学校重置教师密码后要求修改初始密码；首次使用引导按账号保存进度，逐页讲解完整流程和AI工具，设置中可重开。
- 文件夹支持7天邀请CDK，其他教师可独立复制同名目录、子目录、题目及图片快照；限制体积、重复兑换及同名覆盖，支持撤销邀请。
- 重写教师使用指南，说明自动成绩、关系识别、文件操作、共享权限和AI实际能力边界。

## version 1.5.5

- 未修改且无明确归属的旧共享副本隔离保存，教师新增和已修改题目保留，不删除历史原件。
- 学生个人分析增加发布教师过滤，避免共享班级的其他教师成绩混入。
- 网页全选择题提交后自动发布成绩，未答题按0分；混合题型和图片批改仍需教师审核。
- 新发布时间带时区；旧无时区发布时间按北京时间解析，截止时刻即关闭答题；发布记录显示实际时间窗口。
- 切换页面保留导航，流程图按需加载；生产资源预压缩并缓存哈希文件，不缓存入口HTML。
- 题库、组卷列表支持悬浮查看完整题目；目录全选及文件管理器多选、框选、批量移动。
- 批改页显示学生冻结试卷的参考答案；多答案支持嵌套且/或和等价组合，旧语义只由教师助手AI适配，原答案保留。
- 增加1管理员、1学校、3教师、60学生的独立验收环境；本次不生成安装包。

## version 1.5.4

- PDF 预览内置中文字符映射、标准字体和图片解码资源，不依赖外部 CDN；新增缩放、适应宽度、下载及失败重试。
- 同一试卷的分析按发布批次展示，默认最近有效发布；历史批次可选，成绩、用时、监考、题目和班级统计及导出统一使用该批次。
- 历史题目分析优先读取发布时冻结的题目内容，避免修改源题后影响旧考试分析。
- 教师题库题目、图片及新导出文件物理隔离，网页与 AI 文件/文档工具共用权限检查；旧共享题库保留备份并给既有教师独立复制，新教师为空。
- Excel 新增中文成绩单及逐题成绩、同分并列排名、单位和批次编号；未批改成绩留空，用户文本不作为公式执行。
- 修复 CI 中过时的 OCR、账号和图片权限测试；兼容 Anthropic SDK 原生超时类型，保留有界等待和禁用自动付费重试。

## version 1.5.3

- AI 连接测试改为检查首个有效模型响应，兼容思考输出，最长等待 45 秒，结束后关闭连接。
- AI 对话增加 10 秒空闲保活与禁用代理缓冲的响应头，降低反向代理中断长思考请求的风险。
- 关闭 SDK 自动重试；超时不再自动重复完整请求。连接等待 10 秒、连续无响应等待 180 秒，并提供脱敏中文排障提示。
- 学生题目图片支持加载失败提示及重试；覆盖中文嵌入图片标记的回归测试。
- 发布记录改为响应式卡片，直接显示取消发布按钮；三个常用版式预设补全结构初始化和应用反馈。
- 教师题库新增文件夹树、子文件夹、批量移动、重命名与移除分组，关联 AI 工具；逻辑分组不移动题目文件。
- 提供服务器本地文件升级包；保留现有数据和配置，升级后重启应用服务，不要求重启系统。

## version 1.5.2

- 题库新增自定义分类编辑和分类筛选；旧题目自动显示为未分类，导入导出仍保留 metadata.category。
- 模板增加一键100分结构；手动组卷可按当前筛选补齐各题型空缺，保留已选题并去重。
- 新学生账号改为 s 加8位数字；不重号的学号也可登录，旧账号和密码不变。
- 学生作答及复盘支持显示题干、选项中的图片；图片请求携带登录凭证，并校验属于该学生已打开的试卷。
- 图片附件读取与 doc.ocr_image 接入本地 Tesseract，提供 Ubuntu 中英文 OCR 安装脚本；不将 OCR 当作完整视觉/公式识别。
- AI 请求默认直连，仅显式配置的目标域名使用代理；升级时清除旧全局代理配置并保留凭据。
- 新增 bank.create_items：一次确认整批创建，返回逐题结果，拒绝覆盖重号旧题；移除重复工具描述，减少上下文开销。
- 修复取消确认被当作同意的问题；助手可确认后将有明确归属的试卷草稿移入回收站，已发布记录保留并提供撤销引导。

## version 1.5.1

- 修复公网部署中平台 AI 配置无法保存的问题，增加保存后回读与真实连接测试，并对供应商错误进行脱敏提示。
- 管理员工作台改为“学校与账号 / 平台 AI / 扩展组件”全宽分区，消除固定右栏造成的内容拥挤。
- 扩展安装按运行平台处理：Windows 经确认后调用系统安装器，Linux 提供可复制的包管理命令和重新检测流程。
- 新增 Linux 一键升级脚本，包含发布包校验、数据与配置保留、双服务健康检查及失败回滚。

## version 1.5.0

- 为平台、学校、教师和学生补充首次使用清单与可直接执行的下一步入口。
- 修复新增题目或模板后组卷页不刷新，以及已发布成绩人数显示为 0 的问题。
- 学生提交前会核对已答、未答、草稿和剩余时间；成绩发布后支持完整逐题复盘与错题筛选。
- 登录与改密体验中文化，增加密码显隐、二次确认、自助改密及安全的找回指引。
- 智能助手未启用时不再暴露技术配置名，侧栏可收起并改善常用窗口宽度下的可用空间。
- 录题和模板默认使用简单模式；高级公式、绘图、源码与版式按需展开，并提供常用试卷预设。
- 学生开考前可查看题数、总分、限时和截止时间；批改状态、本地时间、风险等级与短时长展示更清楚。

## version 1.4.8
