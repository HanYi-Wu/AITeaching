# 更新日志

## version 1.6.7

- 再次复验补修学校与学生登录误请求教师内容目录的 403；角色切换清除原教师目录，增加真实部署权限场景回归，并将源码内部测试纳入全量 CI。
- 同版本修订：修复连续新建同名模板和试卷、模板变化后的组卷选择状态；新建自动编号，手动重命名仍保护已有内容。
- 补齐文件夹删除、同目录重名处理和归类／试卷文件夹说明；保留源文件、学生答卷及发布记录。
- 修复手机登录卡片居中与小屏裁切、局域网日志复制失败、教师分析页请求管理员接口，以及未交卷时误点发布成绩的问题。
- 保留版本号 1.6.7，更新同一 Release 的源码及 Linux 离线安装包；既有部署需重新下载修订包并执行安装更新。
- 修复题库、模板和组卷的目录编号导致标签读取与保存返回 404；保留教师个人标签隔离。
- 教师目录与标签接口统一校验教师身份，其他角色访问返回明确权限提示。
- 明确声明 httpx 运行依赖，并将 Anthropic 依赖范围与已有 Pixi 配置对齐，修复全新安装的启动及接口兼容错误。
- 中文脚本分析的隔离进程统一使用 UTF-8，修复 Windows 中文图表运行失败；加强真实执行回归测试。
- 统一应用及自身 Rust 锁文件版本为 1.6.7；发布源码和 Linux 离线安装／更新包，构建中验证真实 OCR、安装、升级及回滚。

## version 1.6.6

- 组卷筛选改为弹窗；试卷可独立调整小节题量及分数，不再受模板默认题量锁定。
- 模板、组卷、试卷增加分层目录；试卷目录分归类文件夹与试卷文件夹。旧试卷迁入每位教师的默认归类文件夹，不更改历史答卷和成绩。
- 题库、模板、组卷、试卷增加教师个人标签，支持五字内名称、预设颜色、编辑和内容标记。
- 支持指定学生布置练习，并在试卷文件夹中限制每名学生只收到一份；学生只看到自身任务，班级分析不纳入个人练习。
- 新增文件夹分析及相应 AI 工具；发布前需确认接收对象与文件夹。文件夹交互加入轻量动效，减少动态效果设置下自动关闭动画。

- 保证 100% 行为与样式等价：严格保留全部原有 Tailwind 样式类名、业务逻辑、React 响应式状态流、属性传参及事件绑定，不改变任何路由与用户交互。
- 统一各端应用版本为 1.6.2，保持版本标签发布纯源码与说明，离线打包保留为手动触发。

## version 1.5.6

- 题库空白处取消复选；文件管理器新增右键、剪切粘贴、Shift范围选择、拖动题目及目录移动，上一级导航，保留次级目录关系并阻止循环和覆盖。

- 重写教师使用指南，说明自动成绩、关系识别、文件操作、共享权限和AI实际能力边界。

## version 1.5.5

- 未修改且无明确归属的旧共享副本隔离保存，教师新增和已修改题目保留，不删除历史原件。

- 批改页显示学生冻结试卷的参考答案；多答案支持嵌套且/或和等价组合，旧语义只由教师助手AI适配，原答案保留。
- 增加1管理员、1学校、3教师、60学生的独立验收环境；本次不生成安装包。

## version 1.5.4

- PDF 预览内置中文字符映射、标准字体和图片解码资源，不依赖外部 CDN；新增缩放、适应宽度、下载及失败重试。

- 教师题库题目、图片及新导出文件物理隔离，网页与 AI 文件/文档工具共用权限检查；旧共享题库保留备份并给既有教师独立复制，新教师为空。
- Excel 新增中文成绩单及逐题成绩、同分并列排名、单位和批次编号；未批改成绩留空，用户文本不作为公式执行。
- 修复 CI 中过时的 OCR、账号和图片权限测试；兼容 Anthropic SDK 原生超时类型，保留有界等待和禁用自动付费重试。

## version 1.5.3

- AI 连接测试改为检查首个有效模型响应，兼容思考输出，最长等待 45 秒，结束后关闭连接。
- AI 对话增加 10 秒空闲保活与禁用代理缓冲的响应头，降低反向代理中断长思考请求的风险。
- 关闭 SDK 自动重试；超时不再自动重复完整请求。连接等待 10 秒、连续无响应等待 180 秒，并提供脱敏中文排障提示。
- 学生题目图片支持加载失败提示及重试；覆盖中文嵌入图片标记的回归测试。
- 发布记录改为响应式卡片，直接显示取消发布按钮；三个常用版式预设补全结构初始化和应用反馈。
- 教师题库新增文件夹树、子文件夹、批量移动、重命名与移除分组，关联 AI 工具；逻辑分组不移动题目文件。
- 提供服务器本地文件升级包；保留现有数据和配置，升级后重启应用服务，不要求重启系统。

## version 1.5.2
