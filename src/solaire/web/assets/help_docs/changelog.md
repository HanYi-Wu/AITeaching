# 更新日志

---

## version 1.4.5

- 默认语言调整为中文；仍保留教师主动选择并保存的英文偏好。
- 修复图片答卷在 AI 助手中因提交标识被压缩丢失而无法批改的问题；AI 现在可按学生学号、账号或姓名稳定定位答卷。
- 新增答卷定位、批量 AI 预批改、线下采集指引和学生画像 AI 工具；AI 预批改只写建议，最终分数仍由教师复核保存。
- 历史考试统一展示线上与线下记录；线下考试可下载 Windows 答卷采集器，按学生上传多张试卷照片后复用在线答卷查看、AI 预批改和人工复核流程。
- 新增教师端“学生画像与分析”页面，可按班级查看学生完成率、得分、时长、诚信事件、最近考试和薄弱题目。

---

## version 1.4.4

- 组卷发布页新增“专项复习试卷”：教师选择至少 3 份班级历史试卷后，可按每名学生的历史错题生成同知识点、同难度的举一反三练习；学生三份试卷均无错题时，系统改用相关历史题目生成变式题。
- 历史错题卷与专项复习卷均可设置每名学生的最大题目数量，避免个别学生题量过大。
- 新增专项复习相关 AI 工具，教师可通过智能助手查询可用历史记录、发起生成与发布；生成题目会经过题型、数量、答案和分值校验，并按学生冻结题目与答案，保证后续答题和批改一致。
- 补齐个性化试卷的学生作答、草稿恢复、到时自动提交、教师查看答卷、人工/AI 批改及学情分析闭环。

---

## version 1.4.3

- 组卷发布页新增“历史错题试卷”：教师可选择一份已发布试卷，系统按学生实际错题分别生成个性化练习；没有错题的学生不会收到空白试卷。
- 新增历史错题相关 AI 工具，教师可通过智能助手查询班级历史、选择来源并发布错题试卷，同时保留班级权限和高风险操作确认。

## version 0.2.3

- 加固公网 / FRP 测试边界：显式 CORS、平台会话鉴权、登录限流，以及管理员本机控制令牌。
- 前端主工作区改为按需加载，补齐主壳层中英文文本，并升级存在安全公告的 Web 依赖。
- 修复补练卷 API 回归测试、PrimeBrush Cairo 运行依赖、版本与许可证声明不一致问题。
- 增加 CI、安全回归、仓库元数据和 PrimeBrush Rust 契约测试。

## version 0.1.0

- 新增从学情诊断生成补练卷草稿的闭环：考试分析页可基于薄弱知识点一键生成可编辑组卷草稿，并跳转到组卷页继续微调与导出；智能助手也可调用同一能力。
- 优化进程生命周期管理，集成单实例锁定、动态端口 fallback 与服务就绪自检，显著提升冷启动与多开场景下的系统稳定性。
- 修复了化学绘图失效的问题
