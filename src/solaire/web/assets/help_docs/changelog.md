# 更新日志

## version 0.2.3

- 加固公网 / FRP 测试边界：显式 CORS、平台会话鉴权、登录限流，以及管理员本机控制令牌。
- 前端主工作区改为按需加载，补齐主壳层中英文文本，并升级存在安全公告的 Web 依赖。
- 修复补练卷 API 回归测试、PrimeBrush Cairo 运行依赖、版本与许可证声明不一致问题。
- 增加 CI、安全回归、仓库元数据和 PrimeBrush Rust 契约测试。

## version 0.1.0

- 新增从学情诊断生成补练卷草稿的闭环：考试分析页可基于薄弱知识点一键生成可编辑组卷草稿，并跳转到组卷页继续微调与导出；智能助手也可调用同一能力。
- 优化进程生命周期管理，集成单实例锁定、动态端口 fallback 与服务就绪自检，显著提升冷启动与多开场景下的系统稳定性。
- 修复了化学绘图失效的问题
