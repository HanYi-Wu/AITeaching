# 个人题库：导入、整理与部分导出

每名教师只使用一个个人题库。学科、标签和来源用于筛选题目，不需要创建或管理多个题库。

## 导入

在题库页选择 YAML、Excel 或受支持的文档。系统会先校验题型、选项、答案和公式；不支持的格式会给出明确提示。直接导入标记为“人工导入”，通过 AI 从文件整理后写入标记为“AI辅助导入”。

## 整理

可按学科、题型、标签、来源或关键词筛选。也可以告诉 AI 要保留的范围和整理规则；AI 先列出匹配结果，不会擅自删除题目。

## 文件夹移动与分享（1.5.6）

目录支持父/子关系。文件管理器支持右键、剪切粘贴、拖动题目及整个目录移动；空白取消复选，Ctrl/⌘多选、Shift范围选择、空白框选。目录移动保留子目录，不允许循环或覆盖同名目录。删除目录不删除题目。

选目录后生成邀请CDK，可将生成时的题目、图片及子目录快照复制给持码教师。邀请码7天有效，最多300题、图片50MB；接收者导入后根目录出现同名目录，学科保留，副本互不影响。重复兑换和同名覆盖会被拒绝，生成者可撤销未使用邀请；撤销不删除已复制内容。邀请码只发给授权教师。

## 部分导出

勾选需要的题目后点击“导出所选”。系统生成仅包含这些题目的 YAML 文件。也可以让 AI 查询并整理题目，工具执行完后，对话中会出现可直接下载的文件按钮。

## 来源标记

- AI生成：题目主体由模型生成。
- AI辅助导入：模型依据教师提供的文件转换或整理。
- 人工导入：教师直接导入且未由模型改写。
