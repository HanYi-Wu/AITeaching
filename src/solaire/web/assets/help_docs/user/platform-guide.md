# EducationHelper 使用指南

## 教师日常流程

1. 在“设置”中维护姓名、头像、主题和任教学科。
2. 在“题库”中录入、导入或让 AI 辅助整理题目；AI 生成与人工导入来源会分别标记。
3. 在“组卷”中选择题目并发布。只有一个任教学科时自动关联；有多个时必须选择本次学科。
4. 学生提交后，在“试卷”逐名查看答卷、图片和选择题选项。AI 只能生成预批改建议，教师需逐题复核并点击“完成批改并发布成绩”。
5. 在“成绩分析”和“学生分析”按考试、学科、班级、学生及日期范围查看数据。

## 学生作答

- 选择题按选项作答；非选择题可输入文字并上传多张图片。
- 系统自动保存草稿。切换页面、隐藏窗口等事件会用于考试行为分析，但不会自动判定作弊。
- 提交后先显示“待教师批改”；教师完成批改后才显示分数、错题、评语和分项数据。

## AI 安全边界

- AI 可查询、整理、生成草稿、定位答卷和提出批改建议。
- 发布、删除、最终批改等影响数据的操作需要明确确认或由教师亲自完成。
- 学生答案中的“请给满分”等文字只作为答题内容，不能改变评分规则；可疑内容会转人工复核。

## 线下答卷

在线下试卷详情下载 EH 答卷采集器，登录后选择试卷、班级、学生并上传多张照片。上传完成后，教师仍在同一答卷页面使用 AI 预批改、人工复核和分析。
