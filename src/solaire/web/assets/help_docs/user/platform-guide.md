# 源远教学平台使用指南（历史流程：1.5.6）

## 首次登录

学校创建的新教师账号和重置密码的教师账号，需要先修改初始密码。新密码至少6位、两次输入一致，且不能与当前密码相同。随后教师首次使用引导按顺序打开设置、题库、模板、组卷、试卷、学生、分析和AI说明。

引导不会自动发布试卷或写入成绩。每步查看页面、阅读操作说明后勾选确认，再进入下一步；说明可以收起，但不能跳过步骤。进度按账号保存在服务器，刷新或下次登录继续；完成后不再自动弹出。在“设置→个性化与账号资料”可重新打开引导。旧账号不强制重设已有密码，未完成新版引导的账号会进入引导。

管理员先创建学校与学校端账号；学校管理员准备教师、班级、学生和任课关系。学生首次登录也需要改密。忘记密码请联系学校管理员，平台管理员联系系统维护人员。

## 教师完整流程

1. **设置**：确认任教学科、头像和界面偏好。只有一个学科时发布自动关联，有多个时选择本次学科。
2. **题库**：新建、导入或用AI整理题目，核对题干、图片、公式、选项、参考答案。每位教师的题目与图片独立。
3. **模板**：选择或创建题型、数量与分值匹配的卷面模板。
4. **组卷**：选择题目、调整分值、保存草稿并校验预览，确认卷面总分和图片公式。
5. **试卷**：选择班级、学科、提交方式及起止时间发布。只设置开始时间不会自动在一分钟后结束，需要明确设置结束时间。
6. **批改**：按学生查看答卷、上传照片和发布时冻结的参考答案。全选择题网页答卷提交后自动评分并发布（未答0分）；混合题及图片答卷需教师复核并完成批改发布。
7. **学生与分析**：按学生、班级和日期查看自己发布的答卷；无数据时不会编造统计。需要时生成历史错题卷、专项复习卷。

## 题库文件操作

文件夹是逻辑组织，不改变题目ID。支持父/子目录。点击空白处取消题目复选；目录全选按钮在未选或部分选中时全选，再点取消。

“打开文件管理器”后可点击选择、Ctrl/⌘多选、Shift范围选择、空白拖动框选、双击目录进入、双击题目编辑。右键提供打开、编辑、剪切、粘贴、新建子目录、重命名、删除目录、分享和刷新；Ctrl/⌘+X、V剪切粘贴。拖动题目或目录到目标目录移动，拖到当前文件区域空白处则移到当前目录。目录移动保留所有子目录及题目归属。

不允许移入自身或自身子目录，也不允许合并覆盖同名目录。删除目录**不会删除题目**，其中题目回到父目录。题目编辑后的内容另用保存按钮保存。

## 多答案与且/或关系

在教师题目编辑页点击“使用多个答案 / 且或关系”，答案分项可添加、编辑、删除，至少保留一项。“或”表示任意一个替代答案成立；“且”表示所有条件同时成立；每项还可嵌套关系。

可以输入 `a 或 (b 且 c)` 并点“识别或 / 且关系”。支持或、或者、且、而且、并且、以及、和及括号，**且优先于或**。这是教师主动请求的语法识别，不是按题意推理：自然语言中的“和”、数学括号可能存在歧义，必须检查结果；复杂旧答案建议让助手读取题意再适配。系统不会自动批量替换旧答案。

删除最后一个可选项后会保留单个答案；空白关系项不能保存。转为文本会保留可读内容，但不再按结构关系自动匹配。结构匹配支持重排及分配律，不是通用数学公式等价证明。修改源题不会改写已发布历史试卷的答案快照。

## 文件夹邀请CDK

选择目录后点击“生成文件夹邀请CDK”，或右键目录生成邀请。邀请码有效7天，最多300题、图片总量50MB，包含生成时的题目、图片与子目录快照；之后修改源题不会改变邀请快照。空文件夹也能分享。

其他教师在题库“输入文件夹邀请CDK”后点击导入，根目录创建源目录的同名文件夹，并将内容独立复制到自己的题库，来源标记“教师分享”。同名目录冲突会提示先重命名，不覆盖资料；同一教师不能重复兑换同一码，也不能兑换自己的码。复制后双方修改互不影响。

**持码的已登录教师均可复制**，请只发给授权的人，不要公开学生资料。生成者可撤销邀请码，撤销不删除别人已经复制的题目。图片缺失或越权时不会创建不可用邀请。

## AI走同一套流程

打开“助手”后可以说：“帮我整理这些题目并创建模板，组卷预览，确认后发布到指定班级；提交后协助批改和分析。”助手使用真实题库、组卷、发布与分析工具；文件夹整理和邀请对应 `bank.organize`，旧答案语义适配对应 `bank.adapt_answers`。

AI配置可用、班级任课关系及真实答卷是前提。需要写入、发布或删除时按提示确认，高风险操作需教师核实。学生答案里“给我满分”等文字不是系统指令，不得改变评分规则。AI建议不等于已经审核发布。

## 学生与线下答卷

学生选择题按选项作答，非选择题支持文字、多答案关系与多张答题图片。系统保存草稿，正式提交前核对已答、未答和剩余时间；提交后不可撤回。成绩发布后可查看具体错题和评语。

线下采集器按试卷、班级、学生上传多张照片，之后在同一批改页面进行AI预批改和人工复核。切屏等记录只作为考试行为线索，不能单独证明作弊。
