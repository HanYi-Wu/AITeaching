# 线下答卷照片采集与 AI 预批改

线下考试与在线考试现在使用同一套答卷、批改和学生分析流程。区别仅在于：在线考试由学生在网页作答，线下考试由教师上传每名学生的答卷照片。

## 使用步骤

1. 教师进入“试卷管理”，点击“下载线下答卷采集器”。
2. 打开 Windows EXE，填写当前系统地址，使用教师账号登录。
3. 选择试卷、班级和学生；按页码顺序选择该学生的多张答卷照片。
4. 确认学生姓名和照片数量后上传。每名学生最多 20 张，单张不超过 15MB，总计不超过 100MB。
5. 返回“试卷管理 → 提交批改”，刷新答卷，点击“AI 预批改”或“AI 批量预批改”。
6. 教师逐题检查原图、AI 建议分和反馈，确认无误后亲自保存最终分数。

## 支持格式

支持 JPG、JPEG、PNG、WebP、BMP、TIFF、HEIC 和 HEIF。系统遇到不支持的格式会明确提示，不会静默忽略。

## 安全说明

- 采集器不会保存教师密码，登录令牌只保留在当前运行内存中，关闭后即清除。
- 本机照片必须由教师亲自选择，AI 助手不能读取未授权的文件。
- AI 只生成预批改建议，不会替代教师确认最终分数。
- 正式公网部署应使用 HTTPS 服务地址，避免账号和答卷照片在传输过程中暴露。
- 当前采集器未做商业代码签名，Windows SmartScreen 可能显示“未知发布者”；请只从本系统教师端下载，并由学校管理员核对下载响应中的 SHA-256 校验值。正式大规模部署建议配置代码签名证书。

## 学生画像

教师可进入“学生”页面，综合班级、搜索词和日期范围查看完成率、平均得分率、每题平均时长、平均每场考试行为事件、最近考试和薄弱题目。行为事件仅供人工复核，不等同于作弊结论；数据范围严格限制在教师已分配的班级内。
